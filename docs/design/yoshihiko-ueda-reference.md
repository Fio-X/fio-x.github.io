# 上田义彦网站：设计研究基线

- 研究对象：[Yoshihiko Ueda 官方网站](https://www.yoshihikoueda.com/)
- 研究范围：公开首页与 Information 页面中的信息架构、版式、响应式行为
- 首次核验：2026-07-29
- 用途：为 Fio 首页身份入口、信息型长页和阅读排版提供可追溯的设计基线
- 非用途：复制原站照片、项目名称、履历、出版物数据、Logo、字体文件、源码或品牌表达

## 使用边界

本研究可复用的是：极简首页的身份层级、导航位置、内容轨道、窄阅读列、长信息页的段落节奏和列表层级。

以下内容不进入 Fio：

- 原站摄影作品、封面、出版物图片或文字。
- 原站姓名字标、SVG、日英履历和项目标题。
- 原站字体文件、CSS、JavaScript、动画实现或路由代码。
- 让访客误认 Fio 与上田义彦有关的独特品牌表达。

## 事实与建议的区分

| 标记 | 含义 |
| --- | --- |
| 实测 | 在公开页面或计算样式中直接核验的行为/数值 |
| 推断 | 从实测布局归纳的可行解释，需要在后续复验 |
| Fio 采用 | 已决定用于 Fio 原型的规则 |
| 待决 | 只有生产实现前才需决定的内容或技术规则 |

## 首页：Home

### 实测结构

- 根路径是固定满屏的视觉入口，不是文章列表或营销页。
- Desktop 视口中页面无纵向滚动；主标志约从左侧 `60px` 开始。
- 主导航位于页面底部，包含 `portfolio` 与 `information` 两个入口。
- 首页不显示版权文字、摘要卡片、项目列表、轮播控制器或营销式说明。
- Information 内容已在页面系统中存在，但首页状态只承担身份与入口职责。

### Fio 采用

Fio 首页保留独立的深灰身份入口：

```text
深灰固定满屏
Fio 大型姓名
一句短文本
底部 Latest / Works / Information
无首页版权文字
无自动轮播
```

Fio 不复制原站的字标、项目入口名称或页面转场；保留自己的名称、文本和栏目。

### Fio 未采用

- 不采用原站可能存在的 PJAX/预载内容切换实现。
- 不采用“首页不显示任何辅助文本”的严格规则，因为 Fio 目前需要一句最小身份说明。
- 不在没有真实授权作品时引入媒体轮播。

## Information：长信息页

### Desktop 实测数据

| 项目 | 实测值 |
| --- | --- |
| 左侧导航轨道 | 约 `250px` |
| 正文列宽 | 固定约 `580px` |
| 顶部 padding | `36px` |
| 底部 padding | `142px` |
| 大章节顶部间隔 | `96px` |
| 基础文字 | `13px / 24px` |
| 条目主标题/链接 | `18px / 24px` |
| 元信息 | `11px / 18px` |
| 同组列表条目间距 | `8px` |
| 章节标题下留白 | 约 `38px` |
| 分隔线 | 无；主要依靠留白、字号与行高 |

页面左侧不是传统带背景的“卡片侧栏”，而是轻量的导航轨道：

```text
左侧全局导航：约 x = 30px
Information 分区导航：约 x = 135px
正文内容列：约 x = 250px，宽 580px
```

### Mobile 实测数据

| --- | --- |
| 内容内边距 | `17px 20px 130px 86px` |
| 正文起点 | `x = 86px` |
| 正文列宽 | `284px`，以 `390px` 视口为例 |
| 右侧边距 | `20px` |
| 首个章节顶部 | `47px` |
| 后续章节顶部 | `58px` |
| 基础文字 | `14px / 26px` |
| 条目主标题/链接 | `18px / 21px` |
| 元信息 | `12px / 19px` |
| 同组条目间距 | `17px` |
| 分隔线 | 无 |

原站通过脚本对移动端应用专门状态，而不是单纯依赖缩窄 Desktop 页面。Fio 原型可复用其内容列和节奏，但生产实现应使用标准响应式 CSS，不复制原站脚本机制。

## 内容组织模式

Information 是一个长单页档案，而不是分页列表。

包含的内容模式：

- 人物简介。
- 书籍/出版物列表。
- 展览、奖项、收藏等结构化条目。
- 章节内小间距列表。
- 章节间大留白。
- 分区导航与语义 URL/锚点。

核心设计规则：

```text
导航保持轻量
正文保持窄列
章节使用大留白
条目使用小间距
不依赖边框、卡片、阴影或颜色编码
```

## 字体与层级

- 主系统为 Times/Garamond/明朝系衬线字体。
- 标题普遍使用常规字重，不通过粗体制造过强层级。
- 信息密度来自：小字号元数据、窄正文列、稳定行高、章节留白和列表条目对齐。
- 不使用 Hero 级内页标题；详情或信息页的标题维持约 `18px`。

## Fio 原型采用、待决与延后项

### 本轮原型采用

- 首页的深灰满屏身份入口。
- 首页无版权文字。
- Article、空状态和 404 的窄阅读列：Desktop `250px / 580px`。
- Article Desktop 的 `13px / 24px` 基础排版与 `18px / 24px` 标题层级。
- Article Mobile 的 `86px` 左内容轨道、`20px` 右边距、`14px / 26px` 正文。
- 章节主要依赖留白，不使用常态分隔线。

### 生产前待决

- Information 是否正式作为独立栏目，以及它与 Biography、Publications、Contact 的关系。
- 书籍、履历、奖项、收藏等是否使用 Markdown、frontmatter 或结构化数据模型。
- 是否保留 Desktop 双轨导航，或与川内伦子式 `360px` 侧栏统一。
- 长文章是否永久采用窄列，还是按文章类型变化。

### 明确延后

- 原站的页面切换、预载、PJAX 或动画策略。
- 多语言内容与日英并列布局。
- 真实出版物、履历和收藏数据。

## 与川内伦子基线的关系

两份研究资料服务不同页面意图：

| 页面意图 | 优先基线 |
| --- | --- |
| 首页身份入口 | 上田义彦 |
| News、Works、Publications、Articles、Contact | 川内伦子 |
| 作品媒体流 | 川内伦子 |
| 长文章、信息型单页、空状态、404 | 上田义彦 |

两者不应机械混用。Fio 未来生产实现必须先确定页面意图，再选择对应的内容宽度、导航轨道和排版节奏。
